METHODOLOGY // HOW I WORK

Engineering Process

I start with an idea, break it into manageable steps, build a working version, test it, learn from what breaks, and improve it. I believe in learning by building rather than just watching tutorials.

01

Understand & Scope

Define the actual problem, clarify the inputs and expected outputs, and strip away unnecessary complexity.

02

Architecture & Data Model

Design the data structures, REST API contracts, and database schema before writing large blocks of application logic.

03

Build Working Prototype

Construct a minimal end-to-end working system first so edge cases and bottlenecks become visible early.

04

Test, Break & Improve

Stress-test with real inputs, fix failure points, optimize bottlenecks, and document key lessons.
